# Upstream provenance

This repository is the ManagedCode C#/.NET port of Microsoft's Agent Lightning. The upstream project is [microsoft/agent-lightning](https://github.com/microsoft/agent-lightning). The parity reference used for the current migration matrix is tag `v0.2.0-39-g4cd09ec`, commit `4cd09ec900894cbcc0e832f1acfc3cbc1e2022b8`.

This repository's own MIT license is in [`LICENSE`](./LICENSE). The .NET implementation is maintained in this repository's C# projects. No upstream Python source, Python-only example, test, or runtime/tooling dependency is part of the .NET package or build.

The source revision is recorded here and in Git history for attribution and parity tracking. It is not needed to restore, build, test, pack, or run the .NET projects.
